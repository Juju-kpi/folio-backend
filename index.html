🔒 Privacy & Security

Your files never leave your device

Unlike most PDF tools that upload your files to a remote server, ForgePDF processes everything locally using open-source WebAssembly libraries (PDF.js, pdf-lib) running directly in your browser tab. There is no upload pipeline. It is architecturally impossible for us to access your documents. GDPR compliance is a structural consequence — not a policy checkbox. You can verify this yourself in seconds.

🧠

Local-only processing

PDF parsing, rendering, editing, merging and conversion all run inside your browser tab. File bytes never reach our servers — not partially, not temporarily.

🪪

Anonymous ID only

The only data we store is an anonymous browser ID for credit tracking. No name, no email, no file name, no IP stored, no document content — ever.

✈️

Works offline

Signing, merging, extracting and converting all work with zero internet connection once loaded. No cloud dependency whatsoever for these operations.

🔍

Fully auditable

Open DevTools → Network while editing: you will see zero file upload requests. The source libraries (PDF.js, pdf-lib) are open source and inspectable.

🔬 Verify it yourself — open DevTools → Network tab

credit-check — anonymous ID only · ~200 bytes · ✓ expected
file upload · document content · PDF bytes → 0 requests found

That's it. One lightweight credit check call. Your PDF never moves.

GDPR compliance by architecture: because we never receive your file, there is nothing to delete, anonymise, protect or breach. Your documents exist only on your device — we have no access to them, not now, not ever.

FAQ

Questions & answers

Are my PDF files ever sent to your servers? +
Never. All PDF processing runs client-side using PDF.js and pdf-lib — open-source libraries running via WebAssembly in your browser tab. The only server call we make is a credit balance check containing only your anonymous browser ID — not your file, not its name, not any content. You can verify this instantly: open DevTools → Network → Fetch/XHR and filter while editing. You will find zero file upload requests.
What's the difference between line-by-line editing, form filling and free placement? +
Line-by-line editing lets you click on any existing text block in the PDF to modify it — the original font, size and position are preserved. Form filling works on PDFs that already have interactive fields (AcroForms) — ForgePDF detects them automatically and you click directly into each field. Free placement lets you add a brand-new text block anywhere on any PDF, even one with no form fields at all — you drag it to exact position, resize it, and style it independently. All three modes are available in the same editor session.
Is ForgePDF really free to use? +
Yes. Signing, merging, splitting, annotating and converting PDFs are completely free forever. Text editing and form filling use a credit system — your first session is completely free, and additional sessions start at €0.50. Credits never expire.
Are my documents stored on your servers? +
No. All PDF processing happens locally in your browser using WebAssembly and JavaScript. Your files never leave your device. We only store your anonymous usage credit balance — nothing else. No file names, no document content, no metadata.
What's the difference between the web app and the Chrome extension? +
The web app works in any modern browser — just open the URL and start editing. The Chrome extension adds extra convenience: it detects PDFs as you browse, adds a quick-open button to PDF links, and integrates with your right-click menu. Both use identical local processing — your files never leave your device in either case.
Do my credits expire? +
Never. Credits are tied to your browser's anonymous ID and never expire. Buy them once, use them whenever you need.
What file formats can I export to? +
You can export your edited PDF as PDF (always), or convert pages to JPG, PNG, DOCX (Word), TXT, HTML, or CSV. Batch export all pages at once with a single click.
Can I edit scanned PDFs? +
Line-by-line text editing requires a real text layer — scanned image-only PDFs don't have one. However, signing, annotating, merging, extracting pages and converting to image formats all work perfectly on scanned PDFs.
