Privacy & security

Your documents are
yours alone. Always.

Unlike most PDF tools that upload your files to a remote server, ForgePDF processes everything locally using open-source WebAssembly libraries. There is no upload pipeline. It is architecturally impossible for us to access your documents. GDPR compliance is a structural consequence — not a policy checkbox.

🧠

Local-only processing

PDF parsing, rendering, editing, merging and conversion all run inside your browser tab via PDF.js and pdf-lib. File bytes never reach our servers — not partially, not temporarily.

🪪

Anonymous ID only

The only data we store is an anonymous browser ID for credit tracking. No name, no email, no file name, no IP stored, no document content — ever.

✈️

Offline-capable

Signing, merging, extracting and converting work with zero internet connection once the extension is installed. No cloud dependency whatsoever.

🔍

Auditable

Minimal permissions — no access to browsing history or other tabs. Open DevTools → Network while editing: you will see zero file upload requests.

GDPR compliance by architecture: because we never receive your file, there is nothing to delete, anonymise, protect or breach. Your documents exist only on your device.
