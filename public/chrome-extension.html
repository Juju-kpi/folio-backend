FAQ

Common questions

Everything you need to know before installing.

Yes. ForgePDF runs entirely in your browser using JavaScript. Once the extension is installed, signing, merging, converting and annotating PDFs all work without an internet connection. Text editing requires a brief server check to validate credits, but the actual processing remains local.
Never. All PDF processing happens client-side using PDF.js and pdf-lib — two open-source libraries that run directly in your browser. The only server communication is the credit check API call (which contains only your anonymous user ID, not your file). Your documents are never uploaded anywhere.
The very first time you edit text in a PDF, it's completely free — no payment or account required. After that, text editing costs 0.50 € per session (a session lasts as long as you have the document open). Credits never expire. Signing, merging, converting and all other features remain free forever.
ForgePDF only requests the minimum necessary permissions: access to the current tab to detect when you open a PDF, and storage to save your anonymous user ID for credit tracking. It does not read your browsing history, access other tabs, or have access to any other site. You can audit the full source on GitHub.
Yes. ForgePDF is a standard Chrome extension and works on any desktop platform that runs Google Chrome — Windows 10/11, macOS 12+, and Linux. It also works in Chromium-based browsers like Edge, Brave and Arc. Mobile Chrome is not supported as extensions are not available on mobile.
Text editing requires the PDF to have actual selectable text. Scanned PDFs (image-only) do not have extractable text layers, so editing is not possible on those — this is a fundamental limitation of how PDFs store content. Signing, annotating, merging and converting to image formats work fine on any PDF, including scanned ones.
If a feature doesn't work as expected and consumes a credit unfairly, contact us and we will refund it — no questions asked. Credits are non-refundable in general, but we stand behind the product and will make it right if there's a bug on our end.
